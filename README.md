# 🎧 Rapverse

Web interactiva creada por **Emanuel-gz**, dedicada a Playboi Carti y Cochise.

## 🌐 Visita la web

👉 [Abrir Rapverse](https://emanuel-gz.github.io/Rapverse/)

## Características

- Historia, evolución musical, estilo e influencias de ambos artistas.
- Nueve canciones con portadas, fragmentos de audio y discos animados.
- Búsqueda, filtros, favoritos y galería de fotografías.
- Diseño adaptable a móviles y computadoras.

## Reproducción y favoritos

Escucha los fragmentos directamente en la web, controla la reproducción y ajusta el volumen. Tus canciones favoritas se guardan en el navegador.

## Tecnologías

HTML, CSS y JavaScript. Sin frameworks ni compilación. Publicado con GitHub Pages.

## Créditos

Consulta las [fuentes y los recursos](docs/SOURCES.md).

Proyecto independiente, sin afiliación con los artistas.
