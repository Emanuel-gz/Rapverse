# 🎧 Rapverse
Web interactiva creada por **Emanuel-gz**, dedicada a Playboi Carti y Cochise.

## Características
- Historia, evolución musical, estilo e influencias de ambos artistas.
- Nueve canciones con portadas, fragmentos de audio y discos animados.
- Búsqueda, filtros, favoritos y galería de fotografías.
- Diseño adaptable a móviles y computadoras.

## Tecnologías
HTML, CSS y JavaScript. Sin frameworks ni compilación.

## Ejecutar localmente
Desde la carpeta del proyecto:

```bash
python3 tools/serve.py --port 8000
```

Abre http://127.0.0.1:8000 en tu navegador.

## Pruebas
Requieren Playwright y Chromium instalados.

```bash
node --check script.js
python3 tests/smoke.py -v
```

## Créditos
Consulta las [fuentes y los recursos](docs/SOURCES.md).
